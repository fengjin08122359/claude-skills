# 功能模块关键词映射

> 此文件从 `config/modules.yaml` 同步，详细配置请查看该文件。

| 模块 | 关键词 | 模块路径 |
|------|--------|---------|
| user-module | user, 用户, login, 登录, register, 注册, auth, 权限 | `modules/user-module/` |
| import-module | import, 导入, batch, 批量, upload, 上传 | `modules/import-module/` |
| validation-module | validation, 验证, validate, 校验, check, 检查 | `modules/validation-module/` |
| config-module | config, 配置, setting, env, 环境变量 | `modules/config-module/` |
| api-module | api, 接口, route, 路由, endpoint, controller | `modules/api-module/` |
| db-module | db, 数据库, database, storage, 存储, migration | `modules/db-module/` |
| ui-module | ui, 界面, component, 组件, view, 页面, page | `modules/ui-module/` |
| test-module | test, 测试, spec, e2e, testing | `modules/test-module/` |
| migration-module | migration, 迁移, merge, 合并, transfer, 整合 | `modules/migration-module/` |
| auth-module | auth, 认证, token, JWT, session, 授权 | `modules/auth-module/` |
| init-module | init, 初始化, bootstrap, 启动, setup | `modules/init-module/` |

默认模块：`general-module`
