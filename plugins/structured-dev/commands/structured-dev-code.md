# 开始编码

调用 `coding-principles` skill，加载 4 条代码修改原则。

## 使用方式

```
/structured-dev-code
```

## 加载的原则

1. **编码前先思考** — 明确假设、提问、暴露权衡
2. **简洁优先** — 最少代码、不投机、不过度抽象
3. **外科手术式修改** — 只改必须改的、不顺便优化
4. **目标驱动执行** — 定义成功标准、循环验证

## 自查清单

同时加载 Jest mock 自查清单（`references/self-check-jest.md`）。

## 何时使用

- 开始编写/修改代码时
- 即使是"快速改一下"也应加载
