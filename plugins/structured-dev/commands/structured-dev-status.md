# 查看工作流状态

查看当前工作流上下文状态，包括模块、issues、需求文档和记忆健康度。

## 使用方式

```
/structured-dev-status
```

## 输出内容

### 当前模块

- 识别的功能模块名称
- 模块路径

### Issues 状态

| 模块 | 低难度(pending/completed) | 中难度(pending/implemented) | 高难度(pending/implemented) |
|------|--------------------------|---------------------------|---------------------------|
| [模块] | X / Y | X / Y | X / Y |

### 需求文档状态

| 模块 | 中难度需求数 | 高难度需求数 | 测试计划数 |
|------|-----------|-----------|---------|

### 最近更新

- 最近修改的文件（带时间戳）
- 最近的决策记录

### Memory 健康度

- 总 issue 数
- 待归档 issue 数
- 模块覆盖情况
