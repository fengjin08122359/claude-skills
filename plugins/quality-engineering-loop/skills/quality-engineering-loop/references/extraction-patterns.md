# 三种核心提取模式

PRD 结构化分析的三种提取模式，根据需求类型选择适用模式。

## 模式1：规则元组（适用于计算类/规则类需求）

从 PRD 中提取最小规则单元：

```markdown
## 规则提取

| 规则ID | 规则描述 | 类型 | 约束 | 优先级 |
|--------|---------|------|------|--------|
| R001 | 实付 = 总额 - 优惠 + 运费 | 计算公式 | 无 | P0 |
| R002 | 运费 = f(地址) | 函数映射 | 地址非空 | P0 |
| R003 | 实付 >= 0 | 边界约束 | 强制 | P0 |
| R004 | 地址为空 → 默认运费 | 异常降级 | 必须 | P1 |
```

## 模式2：状态迁移表（适用于状态机/流转类需求）

```markdown
## 状态迁移表

| 当前状态 | 触发动作 | 目标状态 | 条件 | 非法? |
|---------|---------|---------|------|-------|
| 待支付 | 支付成功 | 已支付 | 金额匹配 | 否 |
| 待支付 | 超时30min | 已取消 | 自动 | 否 |
| 已支付 | 取消 | ❌ 非法 | — | 是 |
| 已取消 | 支付 | ❌ 非法 | — | 是 |
```

## 模式3：隐性规则显性化（适用于查询/列表类需求）

```markdown
## 隐性规则提取

| 显性描述 | 隐性规则 | 验证方式 | 风险等级 |
|---------|---------|---------|---------|
| 默认按时间倒序 | 必须有索引 | EXPLAIN 验证 | 高 |
| 仅展示最近3个月 | 需要分页上限 | LIMIT 检查 | 中 |
| 用户查看订单列表 | 权限隔离 | 数据权限测试 | 高 |
```

## 选择指南

| 需求特征 | 推荐模式 | 说明 |
|---------|---------|------|
| 涉及数值计算、条件判断 | 模式1：规则元组 | 提取最小规则单元，便于测试覆盖 |
| 涉及状态流转、生命周期 | 模式2：状态迁移表 | 明确合法/非法迁移路径 |
| 涉及查询、列表、展示 | 模式3：隐性规则 | 发现 PRD 未明确但必须实现的约束 |
| 混合类型需求 | 组合使用 | 按章节分别应用不同模式 |
