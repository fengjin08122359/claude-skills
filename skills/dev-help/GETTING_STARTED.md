# 🚀 开始使用 Dev Help

欢迎使用 **Dev Help** - 你的智能开发助手和任务规划师!

## ⚡ 30秒快速上手

### 第一步: 确认技能已安装

技能已经安装在 `.lingma/skills/dev-help/` 目录,**无需额外配置**!

### 第二步: 尝试第一次调用

在对话中输入:

```
@dev-help 我需要给组合管理页面添加一个导出功能
```

### 第三步: 回答澄清问题

技能会问你一些问题,例如:
- 导出的数据范围是什么?
- 需要哪些列?
- 是否异步导出?

尽量详细回答。

### 第四步: 确认任务列表

技能会生成任务计划,检查:
- ✅ 任务是否完整
- ✅ 时间估算是否合理
- ✅ 优先级是否正确

### 第五步: 开始执行

确认后,技能会开始逐步执行任务!

## 💡 使用技巧

### ✅ 这样做更好

1. **提供详细的需求描述**
   ```
   ✅ "添加导出功能,导出当前筛选的数据,包含名称/经理/规模列"
   ❌ "加个导出"
   ```

2. **及时回答澄清问题**
   - 尽量详细
   - 提供具体选项偏好
   - 说明约束条件

3. **认真确认任务列表**
   - 检查是否有遗漏
   - 调整不合理的估算
   - 提出修改意见

4. **灵活调整**
   - "合并Task 3和4"
   - "Task 2应该优先"
   - "暂停,我要改需求"

### ❌ 避免这样做

1. **需求描述过于模糊**
   ```
   ❌ "做个预警系统"
   ✅ "做个收益率波动预警,超过5%时站内通知组合经理"
   ```

2. **跳过任务确认**
   - 确认是关键步骤
   - 能发现潜在问题
   - 避免后期返工

3. **不提供反馈**
   - 任务不合理要说
   - 时间估算不准要提
   - 有更好建议要讲

## ❓ 常见问题

### Q: 为什么每个任务限制2小时?

**A**: 2小时是平衡点:
- 足够完成有意义的功能
- 不会太长导致难以估算
- 便于进度跟踪和调整

### Q: 实际耗时超过2小时怎么办?

**A**: 正常现象:
- 暂停分析原因
- 必要时重新拆解
- 更新进度跟踪
- 后续任务会调整估算

### Q: 能跳过确认直接执行吗?

**A**: 不建议,但可以说:
```
"不用确认,直接开始执行"
```

### Q: 中途可以改变需求吗?

**A**: 可以:
```
"暂停,我要调整需求"
[说明新需求]
[重新分析和拆解]
```

### Q: 如何查看历史进度?

**A**: 使用 progress-tracker:
```
@progress-tracker 查看项目进度
```
