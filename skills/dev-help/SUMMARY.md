## 🚀 使用方式

### 自动触发
当用户提到以下场景时自动触发:
- "实现XXX功能"
- "添加XXX"
- "修复XXX bug"
- "重构XXX"
- "规划XXX开发"

### 手动调用
```
@dev-help [你的需求]
```

## 🔄 工作流程

```
1. 需求分析 → 2. 信息澄清 → 3. 任务拆解 → 4. 任务确认 → 5. 逐步执行
     ↑              ↑                                              ↓
     └──────────────┘                                    等待用户反馈
   (有不清楚的地方)
```

## 🎓 设计理念

### 1. 2小时时间盒
- 平衡完成度和可估算性
- 便于进度跟踪
- 符合注意力周期
- 降低风险

### 2. 交互式澄清
- 避免理解偏差
- 提高任务质量
- 减少返工
- 建立共识

### 3. 用户确认机制
- 确保方向正确
- 发现潜在问题
- 调整优先级
- 避免浪费

### 4. 渐进式执行
- 小步快跑
- 及时反馈
- 灵活调整
- 降低风险
