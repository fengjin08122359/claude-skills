# 任务模板库

本文档提供常用的任务模板,供 dev-help skill 在拆解任务时参考。

## 前端组件开发模板

### 模板1: Vue 组件创建

```markdown
### Task [编号]: 创建 [组件名称] 组件

**预计时间**: 1.5 小时

**描述**: 
创建一个新的 Vue 组件,实现 [具体功能]

**涉及文件**:
- `src/components/[ComponentName].vue` - 新建组件
- `src/types/[component].ts` - 新增类型定义(如需要)
- `src/styles/[component].less` - 组件样式(如需要)

**验收标准**:
- [ ] 组件能正确渲染
- [ ] 支持所有必需的 props
- [ ] 触发预期的事件
- [ ] 通过单元测试

**依赖任务**: [前置任务或无]

**技术要点**:
- 使用 Composition API + TypeScript
- 遵循项目组件命名规范(PascalCase)
- 添加完整的 JSDoc 注释
```

## 使用指南

### 如何选择模板

1. **根据任务类型选择**
   - 新功能开发 → 组件/API模板
   - Bug修复 → Bug修复模板
   - 性能优化 → 性能优化模板
   - 代码重构 → 重构模板

2. **根据实际情况调整**
   - 修改预计时间
   - 增减涉及文件
   - 调整验收标准
   - 补充技术要点

3. **组合使用模板**
   - 复杂任务可以组合多个模板
   - 例如: "创建组件" + "编写测试" + "配置路由"

### 模板自定义

如果现有模板不适用,可以:

1. **复制最接近的模板**
2. **修改标题和描述**
3. **调整验收标准**
4. **补充特定技术要点**
5. **保存到本项目 references 目录**

### 最佳实践

1. **保持一致性**
   - 同一项目使用相同的模板风格
   - 验收标准格式统一
   - 时间估算方法一致

2. **持续改进**
   - 记录实际耗时
   - 对比预估和实际
   - 优化时间估算

3. **团队协作**
   - 共享常用模板
   - 收集反馈改进
   - 定期更新模板库
