# 快速开始指南

## 🚀 5 分钟上手

### 1. 技能已就绪

会话存储技能已经创建完成，位于：
```
.lingma/skills/session-storage/
```

### 2. 自动触发

当你的会话文本超过 **10,000 字符** 时，技能会自动触发压缩。

你也会看到提示：
```
⚠️ 会话长度：8,500/10,000 字符
建议进行压缩以优化性能。是否继续？
```

### 3. 手动触发

随时可以要求压缩：

**直接指令**:
- "请压缩当前会话"
- "帮我总结一下刚才的讨论"
- "保存当前进度"
- "生成会话摘要"

**指定级别**:
- "轻度压缩"（保留较多细节）
- "中度压缩"（平衡）
- "重度压缩"（只保留核心）

### 场景 3: 问题解决后

**你说**:
> "记录一下我们是怎么解决这个问题的"

**AI 会生成**:
```markdown
## 问题解决记录

### 问题
应用加载大文件时崩溃（内存溢出）

### 根本原因
使用同步方法读取整个文件到内存

### 解决方案
改用 Node.js streams 逐行处理

### 代码对比
```javascript
// ❌ 旧方法
const data = fs.readFileSync('file.csv');

// ✅ 新方法
const rl = readline.createInterface({
  input: fs.createReadStream('file.csv')
});
for await (const line of rl) {
  processLine(line);
}
```

### 结果
✓ 可处理 2GB+ 文件
✓ 内存稳定在 200MB
```

## 🎯 最佳实践

### ✅ 推荐做法

1. **定期压缩**: 每 15-20 分钟或达到 8000 字符时
2. **明确指令**: 说明需要的压缩级别
3. **检查摘要**: 快速浏览确保重要信息未丢失
4. **分级保存**: 重要会话保存多个压缩版本

### ❌ 避免做法

1. **不要等到上限**: 10000 字符才压缩可能太晚
2. **不要过度压缩**: 重度压缩会丢失很多上下文
3. **不要忘记验证**: 压缩后检查完整性

---

## 🆘 故障排除

### 问题：压缩后找不到某个信息了

**解决**:
1. 降低压缩级别（重度 → 中度）
2. 使用关键词搜索原始会话
3. 明确要求保留特定主题

### 问题：压缩后的文本读起来不连贯

**解决**:
1. 反馈给 AI："压缩后的内容不连贯，请改进"
2. 尝试不同的压缩策略
3. 要求保留过渡语句

### 问题：代码被压缩坏了

**解决**:
1. 明确指出："请完整保留所有代码块"
2. 使用中度或轻度压缩
3. 单独请求："只压缩文字部分，保持代码不变"

## 🎓 进阶技巧

### 技巧 1: 增量压缩

不要等到会话很长才压缩，而是：

```
每 10 分钟 → 轻度压缩当前段落
每 30 分钟 → 中度压缩整合
结束前 → 重度压缩生成总摘要
```

### 技巧 2: 主题分离

对于多主题会话：

```
"请按主题分别压缩：
1. 认证实现部分
2. 数据库优化部分  
3. 部署策略部分"
```

### 技巧 3: 定制模板

如果你有固定格式需求：

```
"使用这个模板压缩：
## 问题
## 分析
## 方案
## 结果"
```
