# Session Storage & Compression Skill

智能会话存储与压缩技能，用于优化上下文使用，在会话文本过长时自动或手动进行压缩。

## 📋 功能特性

### 核心能力

- ✅ **智能压缩**: 根据会话长度自动选择压缩策略
- ✅ **多级压缩**: 支持轻度、中度、重度三种压缩级别
- ✅ **质量保证**: 压缩后保留核心信息和上下文
- ✅ **灵活触发**: 支持自动触发、手动触发和混合模式

### 压缩策略

1. **文本摘要压缩** - 移除冗余内容，简化表达
2. **提取关键要点** - 转换为结构化要点列表
3. **删除次要内容** - 识别并删除过时、重复或不重要的对话

## 🚀 使用方式

### 自动触发

当会话文本超过 **10,000 字符** 时自动触发压缩：

```javascript
if (sessionLength > 10000) {
  compressSession('auto');
}
```

### 手动触发

用户明确要求时进行压缩：

```
"请压缩当前会话"
"会话太长了，帮我总结一下"
"保存当前进度"
```

### 混合模式

当会话超过 **8,000 字符** 时提醒用户：

```
⚠️ 会话长度：8,500/10,000 字符
建议进行压缩以优化性能。是否继续？
[立即压缩] [稍后处理] [忽略]
```

## 📊 压缩级别

### 轻度压缩 (减少 20-30%)

**适用场景**: 日常对话，需要保留较多细节

**处理方式**:
- 移除客套话和填充词
- 简化冗长句子
- 删除明显重复内容

**示例**:
```
前："我觉得我们可能应该考虑使用不同的方法，也许是像..."
后："考虑使用不同方法..."
```

### 中度压缩 (减少 40-50%)

**适用场景**: 技术讨论，代码审查

**处理方式**:
- 提取关键要点
- 总结长篇解释
- 删除过时信息

**输出格式**:
```markdown
## 主题：[名称]

### 讨论要点
- 要点 1
- 要点 2

### 决定
- 决定 + 理由
```

### 重度压缩 (减少 60-70%)

**适用场景**: 长时间会话，问题解决过程

**处理方式**:
- 转换为结构化摘要
- 只保留关键路径
- 删除所有非核心内容

**输出格式**:
```markdown
## 会话摘要

**目标**: [要解决的问题]
**方案**: [选定的解决方案]
**结果**: [达成的结果]
**下一步**: [后续行动]
```

## 🎯 最佳实践

### ✅ 推荐做法

1. **尽早压缩**: 不要等到达到上限才压缩
2. **保留原因**: 理由比具体措辞更重要
3. **使用结构**: 多用列表、表格、代码块
4. **测试可读性**: 确保压缩版本易于理解
5. **获取反馈**: 询问用户压缩级别是否合适

### ❌ 避免做法

1. **过度压缩**: 丢失关键上下文
2. **压缩代码**: 代码本身已经很简洁
3. **丢失叙事**: 保持逻辑流畅性
4. **忽略结果**: 总是包含结果信息
5. **跳过验证**: 压缩后检查完整性

## 🔍 故障排除

### 常见问题

**Q: 压缩后找不到重要信息了**
- A: 降低压缩级别，从"重度"改为"中度"
- A: 使用自定义保留列表，明确标记重要内容

**Q: 压缩后的文本读起来不连贯**
- A: 添加过渡短语
- A: 改进聚类算法，按主题分组

**Q: 代码片段被破坏了**
- A: 始终完整保留代码块
- A: 添加语法验证步骤

### 调试技巧

```javascript
// 比较压缩前后的差异
function debugCompression(original, compressed) {
  console.log('原始长度:', original.length);
  console.log('压缩后长度:', compressed.length);
  console.log('压缩率:', (1 - compressed.length/original.length) * 100 + '%');
  
  // 检查被移除的内容
  const removed = diff(original, compressed);
  console.log('移除内容:', removed);
  
  // 检查保留的内容
  const preserved = intersection(original, compressed);
  console.log('保留内容:', preserved);
}
```
