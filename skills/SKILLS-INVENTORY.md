## 🧪 测试相关技能 (4 个)

### 1. **playwright-element-test** ⭐ 新创建
- **用途**: 基于 Playwright MCP 的浏览器功能测试
- **场景**: 
  - 打开网页链接进行功能验证
  - 模拟用户操作（点击、输入、选择、上传等）
  - 多步骤流程测试（登录、购物、支付）
  - 截图和录像记录
- **特色**: 支持有头模式，可实时看到操作过程
- **命令**: `/functional-test`, `/browser-action`

### 2. **webapp-testing**
- **用途**: 使用 Playwright测试本地 Web 应用
- **场景**:
  - 测试本地前端应用
  - 调试 UI 行为
  - 捕获浏览器截图和日志
- **特色**: 支持服务器生命周期管理
- **语言**: Python + Playwright

### 3. **jest-test-generator**
- **用途**: 自动生成 Jest 单元测试
- **场景**:
  - Vue 组件单元测试
  - Vuex Store 测试（state、getters、mutations、actions）
  - API 服务测试
  - 批量生成测试文件
- **特色**: 自动化生成，覆盖全面

### 4. **internal-comms** (内部通讯)
- **用途**: 内部沟通协调相关测试和技能
- **详情**: 需查看具体文档

## 🔧 开发工具技能 (6 个)

### 5. **gulp-command-helper** ⭐ 项目专用
- **用途**: 执行 Gulp 命令管理 Monorepo 项目
- **场景**:
  - 切换不同客户端项目
  - 构建工作区和包
  - 部署应用
  - 同步依赖
  - 管理项目配置
- **核心命令**:
  - `project-change`: 切换项目
  - `workspaces-build`: 构建工作区
  - `packages-build`: 构建工具箱

### 6. **workspace-manager** ⭐ 项目专用
- **用途**: 管理 Monorepo 工作空间
- **场景**:
  - 创建新的工作区应用或包
  - 跨工作空间同步依赖
  - 检查依赖冲突
  - 批量更新包版本
  - 创建功能分支
- **特色**: 遵循项目规范

### 7. **micro-app-route-config** ⭐ 项目专用
- **用途**: 生成微前端路由配置
- **场景**:
  - 添加新路由到微前端应用
  - 配置路由权限
  - 生成 app.json 供主应用分析
  - 设置路由元信息
- **特色**: 符合微前端架构标准

### 8. **api-mock-generator**
- **用途**: 使用 Faker.js 生成 API 模拟数据
- **场景**:
  - 前后端并行开发
  - 生成测试数据
  - 模拟分页响应
  - 配置环境特定的 mock 设置
- **特色**: 使用 Faker.js 生成逼真数据

### 9. **typescript-type-generator**
- **用途**: 自动生成 TypeScript 类型定义
- **场景**:
  - Vue 组件 Props 类型
  - API 请求/响应类型
  - Vuex Store 类型定义
  - 从现有代码提取类型
  - 批量生成类型定义
- **特色**: 自动化提取和生成

### 10. **mcp-builder**
- **用途**: 创建高质量 MCP (Model Context Protocol) 服务器
- **场景**:
  - 集成外部 API 或服务
  - 为 LLM 提供工具调用能力
  - Python (FastMCP) 或 Node/TypeScript (MCP SDK) 开发
- **特色**: 专注于 LLM 交互质量

## 🎨 设计与可视化技能 (6 个)

### 11. **echarts-chart-builder** ⭐ 项目常用
- **用途**: 生成 ECharts 图表配置
- **场景**:
  - 创建折线图、柱状图、饼图等
  - 应用自定义主题
  - 响应式图表配置
  - 大数据集优化
  - 导出 TypeScript 配置
- **特色**: 内置主题支持和响应式设计

### 12. **frontend-design**
- **用途**: 创建独特的前端界面
- **场景**:
  - Web 组件和页面开发
  - 着陆页和仪表板
  - React/Vue 组件
  - HTML/CSS 布局
  - 样式美化
- **特色**: 避免通用 AI 美学，注重独特性

### 13. **canvas-design**
- **用途**: 使用设计哲学创建视觉艺术
- **场景**:
  - 海报设计
  - 艺术品创作
  - 静态设计作品
- **输出**: .md（设计理念）、.pdf/.png（最终作品）
- **特色**: 先创建视觉哲学，再表达为设计

### 14. **algorithmic-art**
- **用途**: 使用 p5.js 创建算法艺术
- **场景**:
  - 生成式艺术
  - 算法艺术创作
  - 流场和粒子系统
- **输出**: .md（算法哲学）、.html（交互式查看器）、.js（生成算法）
- **特色**: 种子随机性和交互式参数探索

### 15. **theme-factory**
- **用途**: 为各种作品应用主题样式
- **场景**:
  - PPT 幻灯片美化
  - 文档样式
  - HTML 着陆页
  - 报告排版
- **特色**: 10 个预设主题，包含配色和字体方案

### 16. **brand-guidelines**
- **用途**: 品牌指南和设计规范
- **详情**: 需查看具体文档
